# UNILOOP dark Space UI frontend

Research and implementation date: 2026-10-10. Branch: `feat/space-ui-dark-v3`.

Space UI supports both light and dark themes; its neutral dark theme is the foundation here. UNILOOP uses charcoal surfaces, off-white text, violet actions and occasional cyan/green status accents. The marketplace's pages, server actions, data adapters and account access rules remain intact. No backend migration or deployment is included.

## Free and paid research

Official sources:
- https://www.spaceui.one/pricing — Community is free, with 60+ primitives/components, both themes, Tailwind and Motion. Pro includes additional components, shaders, blocks and premium templates.
- https://www.spaceui.one/docs/installation/manual — code ownership, Base UI integration, registry installation and dark design tokens.
- https://github.com/usespaceui/ui — MIT license for publicly available source.
- https://www.spaceui.one/components/filters — public free filter component.
- https://www.spaceui.one/components/gradient-file-upload — public free animated file picker; its simulated upload must not be confused with backend persistence.
- https://www.spaceui.one/components/morphing-search-pill — Pro component; its registry returned HTTP 401. No gated code was retrieved or copied.

Pricing and free catalogue can change. No purchase or paid dependency is required for this implementation.

## Source provenance

Existing free Space UI Button, Badge, Skeleton and Spinner are retained. Input, Textarea, Card, Dialog and Separator are vendored from the public registry at `https://www.spaceui.one/r/primitives-{name}.json`. MIT attribution is included in each file and `docs/licenses/SPACE-UI-MIT.txt`.

Imports are adapted to local paths. The Input, Dialog and Separator wrappers accept static class strings to match the local class utility. Dialog uses a native overflow container instead of bringing in ScrollArea. Inputs use the official native-input option with UNILOOP's own responsive control styling. Native hidden, radio, checkbox, select and file elements are kept to preserve HTML form behavior. Existing implicit-submit buttons explicitly retain `type="submit"` when migrated to Space UI.

The publicly available Filters, Gradient File Upload and Date Selector examples were reviewed. Their full dependency graphs were unnecessary for UNILOOP's current URL filters, local photo preview and native date forms. Those flows use adapted free primitives and original styling instead. No unconnected sorting controls, simulated upload success, sample listings or paid components were added.

## Frontend changes

- Semantic dark tokens replace hardcoded light colors in both existing stylesheets, including private workspaces, chat, notifications, rental controls, moderation and error states.
- Space UI controls cover forms, submission actions, gallery buttons and secondary routes. Cards and Separator support the workspace and footer; free Dialog manages focus and Escape in the mobile category filter.
- Original cool-light hero, squircle cards and border effects preserve the existing home content and marketplace illustration.
- Original expanding header search works on desktop/mobile, opens with `/` or Ctrl/Cmd+K outside editable controls, dismisses with Escape, and submits to the existing explore route.
- Photo selection supports drag-and-drop with the same MIME, size and count checks. Photos remain explicitly local previews until the existing real upload flow is used.
- Dark native controls, visible keyboard focus, selected states and reduced-motion support are shared across the frontend. Reveal content stays visible during SSR and reduced-motion hydration; motion progressively enhances already visible content.

## Verification

The existing 22 unit tests pass locally. GitHub's web quality gates run typecheck, lint, production build, HTTP smoke and Chromium interaction checks. Browser coverage includes seven home widths (320–1440px), search mode navigation, the posting wizard, dark surfaces and readable body text on 17 secondary routes, keyboard search, desktop mode selection, validated photo drops/removal, and category dialog navigation preserving query and mode. Screenshot artifacts are generated by the workflow for visual review.

Local dependency installation was blocked by the environment's minimum-release-age rule for versions already in the repository lockfile. No dependency version or safety setting was changed to bypass that rule. Build and browser results must be taken from the exact branch commit's CI run.

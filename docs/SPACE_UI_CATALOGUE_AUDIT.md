## Evidence and scope
Live catalogue pages reviewed: https://www.spaceui.one/components , https://www.spaceui.one/hooks , https://www.spaceui.one/interactions . Public source https://github.com/usespaceui/ui , verified origin/main snapshot `7b22c0b494cec56a2f569c3a1dd4ceab604b4c53`. The linked pages include Pro entries: not everything displayed is free. Every public catalogue MDX entry was read, its MDX Pro flag, live catalogue Pro tags and installation names checked, and all available linked registry implementation files read and fingerprinted. This is a complete documented source/catalogue audit, not a claim that every interactive demo was manually exercised. Sources without a linked implementation are not treated as free installable components.
